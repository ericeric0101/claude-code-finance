# Research OS quality reviews（選用）

結構化的 review 結果存在 `../quality-events.jsonl`（`python3 scripts/quality_review.py review <id>`），
人工修正存在 `../corrections.jsonl`（append-only）。這個資料夾只放需要較長文字說明的 review 筆記，
檔名建議 `YYYY-MM-DD-<quality_event_id>.md`，並在筆記中引用 quality_event_id 與相關 state 檔案路徑。
不要貼上完整 SEC filing 或報告內容；不要用股價後來的漲跌當作品質證據。
