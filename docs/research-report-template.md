# Project Equity Research Decision Template

Use this project-owned supplement with the upstream stock-analysis report template.
It controls the recommendation and valuation decision layer; it does not replace
sector, accounting, source, risk, or diligence requirements.

**Language:** write the report prose in Traditional Chinese (繁體中文); tickers,
field names, metric abbreviations and code identifiers may stay English.

## Decision summary

**Action:** [BUY / ACCUMULATE / WATCH / HOLD EXISTING / AVOID] — [evidence-based
reason]. **Price/date:** [close and date]. **Valuation confidence:** [high /
medium / low]. State that the action is not derived from a single valuation
method or a fixed margin-of-safety haircut. HOLD EXISTING is permitted only when
the user disclosed an existing position.

## Investment Interpretation

Answer what the market is pricing in, what operating delivery could make the quote
reasonable, what could make it materially overvalued, and what evidence would
change the action. Explain that WATCH is not a required entry price and does not
mean waiting for a crash. A far-below-market zone must be presented with its
reverse-DCF context and catch-up alternatives when supportable.

Any extra haircut must be optional, with the exact label **“Optional margin-of-
safety reference based on one valuation method.”** Check for risk already
embedded in WACC, terminal assumptions, reinvestment, ROIIC, margins, SBC,
normalized cash flow, scenario weighting and multiple normalization. Warn when an
additional haircut may double-count conservatism.
