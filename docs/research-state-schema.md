# Company research state schema

Each tracked company lives in `research/<TICKER>/`. Tool:
`scripts/research_state.py` (local, no network). Derived files from the
2026-10-11 runs are regenerated by `scripts/migrate_legacy_state.py`.

## Authority rules

1. **Primary filings** (SEC, issuer) are the ultimate source of financial facts.
2. **Dated reports and their input/output JSON** (`<TICKER>-analysis-<date>.md`,
   `financial-data.json`, `filings-data.json`, `recommendation-*.json`,
   `normalized-valuation-*.json`, ...) are authoritative for that research date.
   They are never moved or rewritten; new research creates new dated files.
3. **State files** below are the authoritative *current* view and point to the
   dated files they summarize (`source_report`, `authoritative_inputs`,
   `authoritative_source`). A test checks that valuation state matches the
   dated recommendation inputs, so the two cannot silently diverge.
4. **History files** are append/upsert only (same date replaces, older dates kept).

## Layout

| Path | Format | Authoritative for | Written by |
|---|---|---|---|
| `company-profile.md` | md | Identity (CIK, fiscal year, basis), role, links | init / analyst |
| `evidence/sources.json` | json | Source register: id, tier, type, period, filed, URL, retrieval | migrate / update |
| `evidence/{filings,earnings,presentations,announcements,external}/` | files | Saved documents worth versioning (large raw filings stay in ignored `raw/`) | update |
| `management/statements.json` | json list | Management statements per period × topic (`verbatim` flag) | management-change |
| `management/promises.json` | json list | Promise tracker (`pending`/`delivered`/`partially_delivered`/`missed`/`superseded`) | management-change |
| `management/changes.md` | md | Wording-change tables | management-change |
| `financials/historical.csv` | csv | Long-format facts (period, metric, value, unit, basis, classification, source) | migrate / update |
| `financials/latest.json` | json | Latest metrics used by monitoring rules, each with period / classification / source | migrate / update |
| `thesis/current.yaml` | yaml | Current thesis components, action, confidence, next catalysts | thesis-monitor |
| `thesis/history.json` | json list | Thesis snapshots upserted by `as_of` | `research_state.py snapshot` |
| `thesis/invalidation-rules.yaml` | yaml | Observable invalidation conditions and whether triggered | thesis-monitor |
| `valuation/assumptions.json` | json | Method assumptions (labelled Assumption) | valuation-monitor |
| `valuation/latest.json` | json | Current methods, reverse DCF, map, expectations, catch-up inputs | valuation-monitor |
| `valuation/history.csv` | csv | Valuation history upserted by `as_of × method` | `research_state.py record-valuation` |
| `market/prices.csv` | csv | Dated prices with source and retrieval time | price_reaction fetch / migrate |
| `market/event-reactions.csv` | csv | Event reaction observations; interpretation column analyst-owned | price_reaction analyze |
| `monitoring/rules.yaml` | yaml | Fundamental warnings and price reassessment levels | research-monitor |
| `reports/` | md | `index.md` + `YYYY-MM-DD-change-report.md` | change-report |

## Key field contracts

- Thesis component: `importance` ∈ {high, medium, low}; `status` ∈ {supported,
  improving, uncertain, weakening, invalidated}; `evidence[]`, `last_updated`,
  `next_check`, `invalidation_condition` required (validated on snapshot).
- `valuation/latest.json` must not contain `buy_range`, `entry_price`,
  `target_buy_price` or `required_entry_price` (rejected by the tool).
- `reverse_dcf.status` is `quantified` or `not established` (with reason).
- `expectations.{market_implied, internal_base, bull}` use matching metric keys;
  `expectation_gap.previous_metrics` holds the prior run for direction.
- Every metric carries `classification` ∈ {Fact, Calculation, Assumption, Interpretation}.
- Rule `meaning` is always "reassess"; never an order.

## Level 3 files (2026-10-13)

| Path | Contents |
|---|---|
| `financials/history.json` | annual + quarterly metrics with per-metric provenance (tag, form, filed, accession; derivations) |
| `financials/coverage.json` | periods present, ≥5Y / ≥8Q flags, missing metrics, tag fallbacks |
| `financials/tag-overrides.json` | optional extension tags for company KPIs (backlog, ARR, …) |
| `management/guidance.json` | guidance ranges: issued, period, metric, low, high, unit, statement, source |
| `management/reported-kpis.json` | company-reported non-GAAP figures per quarter / FY |
| `management/promises.json` | + `guidance`, `actual_result`, `evidence`, `resolved_date`, `resolution_rule`, `superseded_by` |
| `snapshots/<date>.json` | full multi-domain state; `retrospective: true` = rebuilt from data public at that date, no recommendation |
| `valuation/assumption-check.{json,md}` | Base / Bull assumptions vs history (Below / Near / Above / Materially above) |
| `valuation/historical-multiples.csv` | no-look-ahead price, market cap, EV, TTM fundamentals, EV/Sales, EV/EBIT, P/E, P/FCF |
| `valuation/historical-percentiles.json` | current multiple vs 1Y / 3Y / since-listing month-end values |
| `valuation/expectation-gap-history.csv` | date, metric, market_implied, base, bull, gap_vs_base, gap_vs_bull, direction, confidence |
| `market/fundamental-price-timeline.csv` | per earnings release: price before / after, abnormal moves, fundamentals, EV/Sales, research state |
| `market/benchmark.json` | optional `{"benchmark": "SPY", "sector_etf": "..."}` |
| `thesis/invalidation-rules.yaml` | + optional machine `checks` (`metric`, `warning`, `consecutive_quarters`) and `logic: any` |
| `qa/` | stock-analysis `ratios.py` / `verify_data.py` inputs and outputs from INIT |
| `research/benchmarks/<SYMBOL>/prices.csv` | benchmark closes for abnormal returns |
| `research/reviews/YYYY-MM-monthly-review.md` | monthly multi-company review |

## Level 4 files (2026-10-13)

| Path | Contents |
|---|---|
| `config/watchlist.yaml` | watchlist (not a portfolio): ticker, cik, sector, research_role, priority_override, enabled, macro_links |
| `config/research-policy.yaml` | market / staleness / priority / queue / scan thresholds (Assumptions) |
| `config/kpi-registry/<layer>.yaml` | common + sector KPI definitions (name, definition, concept, unit, required, sources) |
| `<T>/config/kpis.yaml` | company KPIs, `disable`, manual `values` (original name, definition, source), `guidance_metrics`, `milestone_subjects` |
| `<T>/financials/kpi-history.csv` | date, period, kpi, value (`unavailable` when missing, never 0), unit, source, source_type, confidence, notes |
| `<T>/financials/kpi-coverage.json` | required / optional KPIs available vs unavailable, errors, draft flags |
| `<T>/management/claims.json` | structured claims: point / range / qualitative guidance, timing promise, operational milestone |
| `<T>/management/semantic-diff.{json,md}` | FACT / CHANGE / INTERPRETATION / CONFIDENCE findings per topic and dimension |
| `<T>/management/guidance-vs-actual.{json,md}` | guidance vs actual table and status counts (or "No explicit evaluable management guidance found.") |
| `<T>/management/promises.json` | + statuses `delayed`, `not_evaluable`; + `metric_definition`, `comparison_basis`, `resolution_confidence`, `actual_source`, `draft_auto`, `review_required` |
| `<T>/monitoring/scan-state.json` | last_checked, last_filing, last_price_update, last_management_update, seen accessions, triggered rules, promise statuses |
| `<T>/monitoring/tradingview-alerts.md` | optional P2 alert text (REASSESS only) |
| `<T>/exports/notebooklm-sources.md` | optional P2 NotebookLM source list (repo stays canonical) |
| `research/queue/current.json` | research queue items (event_id, ticker, event_type, detected_at, priority, required_workflow, source, reason, status, …) |
| `research/queue/priorities.json`, `priority-history.csv` | ticker priority with reasons and rank; history upserted by date |
| `research/queue/archive/YYYY-MM.json` | closed items older than `queue.archive_after_days` |
| `research/calendar/upcoming.csv` | ticker, event, expected_date, date_precision, window_start, window_end, source, confidence, importance, status, notes |
| `research/dashboard/current.{md,json}` | command-center table, answers, confidence components, open queue |
| `research/dashboard/stale-research.{md,json}` | stale research findings |

Promise rule: a guided metric is auto-resolved only when `comparison_basis` is one of
`gaap_match`, `definition_match`, `same_company_metric`, `calculated_gaap`; otherwise it is
`not_evaluable` with the reason.
